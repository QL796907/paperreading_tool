# 术语本

读论文碰到不会的词，可以从 Zotero 里划一下，收进这本子。按日期一页页翻，解析能自己写，也可以让 AI 帮忙写。电脑和手机能看同一本。

当前版本 **1.0.7**。

这一版有三处会碰到的变化。电脑窗口的标题栏回到之前的米色，书页铺满窗口，四周不再留一圈深色边。坚果云上还没有术语本文件夹时，同步会自己建好并上传，不再提示网盘返回 409。设置里填好 AI 地址、密钥和模型后，可以先点「测试连接」，确认接口能用再保存。

设置里仍默认勾选「使用镜像下载更新」，国内下更新更稳；说明在 [gh.4o.pw](https://gh.4o.pw/docs)。不想用镜像，取消勾选即可。

已经装上 1.0.4、1.0.5 或 1.0.6 的手机可以直接装这一版。更早的版本签名不同，请先卸载再装。电脑和 Zotero 插件可以直接覆盖安装。

## 怎么装、怎么打开

**电脑：** 打开刚下的安装包，按提示装完，从桌面或开始菜单点「术语本」。若弹出「Windows 已保护你的电脑」，点「更多信息」，再点「仍要运行」。

关掉窗口后，它会躲到右下角托盘，并没有退出。真要退出，请右键托盘图标。

**手机：** 允许安装未知应用后，打开刚下的安装包。装好后直接进术语本。手机上不能从 Zotero 划词。

**Zotero 插件：** 需要 Zotero 7。打开 Zotero → **工具** → **插件** → 右上角齿轮 → **Install Add-on From File**，选刚下的插件，然后重启 Zotero。术语本开着时，词会马上出现。术语本已经退出时也可以加入，下次打开就能看到。

## 第一次怎么用

1. 打开电脑上的术语本。
2. 在 Zotero 里打开一篇 PDF，选中术语，在选区里点「加入术语本」。也可以在术语本里点「添加术语」，自己写进去。
3. 回到术语本，左边按日期找，当天那一页就能看到新词。
4. 解析可以手写。想让 AI 写，打开右上角「设置」填你的 AI，可以先点「测试连接」；暂时不会填，就先手写。
5. 电脑和手机要看同一本：两边都在设置里打开坚果云同步。

想放大来看，点「展页阅读」，可以像翻书一样翻当天的词。

## 卡住时看这里

- 装的是 1.0.4、1.0.5 或 1.0.6，手机可以直接覆盖。更早的版本如果被系统拦住，先卸载再装。卸载不会经过坚果云，卸之前先在设置里同步一次，避免词条只留在手机上。
- 关掉窗口不等于退出。托盘里点「退出」才会真正关掉。退出之后，Zotero 里仍可以加入术语，下次打开术语本就能看到。自动解析要等打开后再做。
- 手机没有划词。词在电脑上加，再用坚果云同步过来。
- 左下角写着同步失败时，点那一行就能打开设置。测试连接成功只说明账号能登录，同步还要把术语本写进网盘。网盘上还没有术语本文件夹时，同步会自己建好。
- 插件只连这台电脑上的术语本。术语本已经退出时，词会先记在这台电脑上。换一台没装术语本的电脑，划词加不进来。
- 电脑会在后台下载更新。下好后页面上方会出现「现在更新」，点一下就装好并重新打开，不再弹出安装窗口。从托盘退出时，如果更新已经下好，也会一并装上。手机请到设置里点「检查并安装更新」。下得很慢或失败时，打开设置确认「使用镜像下载更新」是勾上的。
